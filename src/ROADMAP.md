# ROADMAP

## Главная цель

Создать профессиональную PWA-платформу для косметолога, построенную по модульной архитектуре, пригодную для масштабирования и коммерческого использования.

---

# Принципы разработки

1. Сначала архитектура — потом код.
2. Один источник данных для каждой сущности.
3. Никакого дублирования логики.
4. Каждый модуль независим.
5. UI отделён от бизнес-логики.
6. Все изменения фиксируются в CHANGELOG.
7. Любая новая функция должна вписываться в архитектуру.
