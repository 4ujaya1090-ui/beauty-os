# Beauty OS

## О проекте

Beauty OS — профессиональная PWA-платформа для косметолога-эстетиста.

Это не сайт и не обычная CRM.

Главная цель проекта — объединить управление клиентами, процедурами, записью, медицинскими картами, знаниями и финансами в единую систему.

---

## Цели проекта

- удобная ежедневная работа косметолога;
- единая база клиентов;
- медицинские карты;
- календарь записи;
- каталог процедур;
- бонусная система;
- финансовый учет;
- энциклопедия косметологии;
- установка как приложение (PWA).
