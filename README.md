# Beauty OS

**Beauty OS** — модульная платформа для специалистов сферы услуг и их клиентов.

Проект объединяет управление клиентской базой, онлайн-записью, процедурами, рекомендациями, историей посещений, фотографиями, контентом и личным кабинетом клиента в единой системе.

---

# Что такое Beauty OS

Beauty OS — это не просто CRM.

Это платформа, объединяющая специалиста и клиента в одном приложении.

Каждый пользователь получает собственный интерфейс, соответствующий своей роли.

Система построена как PWA и рассчитана прежде всего на удобное использование с мобильных устройств, при этом доступна и в веб-версии на ПК.

---

# Роли пользователей

## Специалист

Рабочее пространство для управления клиентами, расписанием, процедурами и рабочими процессами.

## Клиент

Личный кабинет с историей посещений, рекомендациями, фотографиями и возможностью онлайн-записи.

# Контент и Telegram

Beauty OS поддерживает интеграцию с Telegram для коммуникации с клиентами и специалистом.

- специалист получает уведомления о новых клиентских записях
- клиентам отправляются напоминания о предстоящих процедурах
- Telegram-канал специалиста используется как источник статей для Beauty OS
- статьи из Telegram-канала могут автоматически появляться в системе

# Статус проекта

Проект находится в активной разработке.

Основной пользовательский контур уже работает: специалист и клиент используют отдельные интерфейсы, доступна онлайн-запись, управление клиентами и процедурами, а также Telegram-уведомления и контентная интеграция.

Архитектура платформы продолжает развиваться, поэтому отдельные функции и направления находятся на стадии дальнейшей разработки.
Подробный план разработки находится в файле ROADMAP.md.
