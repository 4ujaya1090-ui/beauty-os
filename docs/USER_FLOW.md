# USER FLOW

## Главный принцип

Пользователь никогда не должен искать нужную функцию.

Каждое действие должно выполняться за 2–3 нажатия.

---

# Главный экран

↓

Косметолог открывает приложение.

Видит:

- Следующая запись
- Сегодняшняя статистика
- Быстрые действия

↓

Переходы:

- Календарь
- Клиенты
- Процедуры
- Финансы
- Энциклопедия
- Профиль

# Правило навигации

Любой экран должен позволять попасть:

- назад;
- на главный экран;
- к связанным данным.

Например:

Карточка клиента

↓

Запись

↓

Процедура

↓

Оплата

без поиска по меню.
