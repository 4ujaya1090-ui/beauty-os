# DESIGN SYSTEM

## Цель

Интерфейс должен выглядеть дорого, спокойно и современно.

Приоритет — удобство работы косметолога.

Красота никогда не должна ухудшать удобство.

---

# Основные принципы

• Минимум визуального шума

• Максимум воздуха

• Крупные зоны нажатия

• Единый стиль компонентов

• Единая сетка отступов

# Правила

Не использовать инлайн-стили.

Не дублировать CSS.
