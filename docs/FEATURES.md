# Beauty OS Features

## Концепция

Beauty OS — модульная платформа для специалистов сферы услуг и их клиентов.

Система строится вокруг единой модели пользователя (User), который получает определённую роль после авторизации.

---

# Роли

## Professional

Специалист.

Использует систему для ведения своей профессиональной деятельности.

---

## Client

Клиент.

Использует систему для взаимодействия со специалистом.
